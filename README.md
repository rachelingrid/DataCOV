# andesedepoisCOV19
Antes e depois da COVID-19 no SUS: compara internações (SIH) e óbitos (SIM) por qualquer CID-10 ou procedimento, ano a ano, por faixa etária e sexo, com taxas por milhão (IBGE) e testes estatísticos. Dados do DATASUS atualizados pelo GitHub Actions; site estático que funciona offline.
